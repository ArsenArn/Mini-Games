# Sand Worms

Buildless Canvas 2D прототип: 20 заданных уровней, мышь и touch. Открыть `index.html`; при необходимости локального HTTP выполнить в этой папке `python -m http.server 8080` и открыть `http://localhost:8080`.

Голову с глазами или хвост с двумя точками можно тянуть по клеткам. В одном drag поддерживается возврат по пройденному маршруту. Любой сегмент у стенки собирает свой цвет в локальном радиусе. Полный червь исчезает, пустой резервуар остаётся непроходимым. Управление и правила физики сохранены.

Сетки индивидуальны: 4×7–8×12, включая резервуары; длина тел 2–7. Первые десять обучают, 11–14 вводят замкнутые обходы, S-проход, подкову и тупики, 15–17 связывают парковки в плотных контурах, 18–20 требуют обмена карманами и повторного прохода маршрутов. Детали и предполагаемые решения: [LEVEL_DESIGN.md](LEVEL_DESIGN.md).

Восемь цветов чередуются по уровням, включая отдельные синий и бирюзовый, нефритовый и лаймовый. Сердце, цветок, звезда, алмаз, кольца, мозаика, волны, шевроны и бабочка составлены из настоящих частиц. Фон рисунка тоже нужно собрать. На 15/17/20 один многоцветный резервуар; отдельные одноцветные коробки удалены. Служебной белой плашки на резервуарах больше нет.

Симуляция прежняя: 8×8 частиц на клетку, падение вниз и по свободным диагоналям внутри маски. У всех стартовых тел оставлен промежуток до резервуара. Вместимость не зависит от длины: весь песок цвета в уровне делится между его червями поровну, остаток распределяется по одному. Particle Counts показывает живой песок / свободную вместимость; по каждому цвету эти числа должны совпадать.

Debug Menu: **Radius 1.2 клетки / Collection Speed 300 частиц/с / Simulation 1×**. Параметры применяются сразу; Restart и переключение уровней их сохраняют до перезагрузки страницы. Несколько контактов расширяют область, но не умножают скорость. Нулевая Simulation останавливает гравитацию, не сбор.

Первыми вручную проверить 15–20, особенно обмен нижних парковок, смену ведущего конца и остатки рисунка за другим цветом. Предполагаемые решения записаны, но полные прохождения не доказаны. Solver, перебор состояний и автоматические playthrough не выполнялись; физический телефон не проверялся. Для проигрышной расстановки есть Restart. Нет сохранения прогресса и автоматической прокладки пути.

Лаунчер: Sand Worms стоит первой карточкой в общем каталоге. При открытии используется общий вход с сохранением выбора ПК/телефона, режимами и обучением. В обычном режиме Debug и тестовые стрелки скрыты; новые уровни открываются кнопкой после победы. В режиме разработчика доступны все тестовые инструменты. Кнопки `?` и `Меню` позволяют открыть справку, сменить режим и вернуться в лаунчер. Открытое меню/справка приостанавливает игру. При возврате к обычному режиму восстанавливаются параметры 1.2 / 300 / 1×. Для запуска папку игры нужно сохранять внутри Mini-Games рядом с общими `entry-flow.js` и `menu-system.css`.
